# ILM Mizan — Grand Opening Timeline

2026–2030 strategic roadmap and progress tracker.

## Website
Static dashboard lives in `index.html`. It needs no build step. All checklist changes, custom tasks and notes are stored **in your current browser only** via localStorage.

## Important
- Use **Export JSON** regularly to back up your progress and **Import JSON** to restore it on another device.
- Dates and revenue targets are planning hypotheses, not promises.
- The original repository is **private**. GitHub Pages availability for private repositories depends on the GitHub account/plan. Publishing Pages publicly can expose the site even when source is private.
- To publish: Repository → Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save (if your account permits). 
- Do not store API keys or confidential client data on the static site or its exported JSON.
